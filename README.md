# simple_map プロトタイプ（クリック動作モック）

ワイヤーフレーム/デザインカンプ/機能説明書を元にした、**見た目と画面遷移だけ**を再現した
動くプロトタイプです。Vue 3（CDN読み込み・ビルド不要）で作っています。

## フォルダ構成
```
simple map dev/
├─ index.html      ← これを開く
├─ css/style.css
├─ js/data.js       ← モックのスポットデータ
└─ js/app.js        ← 画面遷移・状態管理（Vue本体）
```

## スマホでテストする方法（一番簡単）
1. このフォルダを `D:\programs\simple map dev` に置く
2. VSCodeの拡張機能「Live Server」などでこのフォルダを開き、`index.html` を配信する
   （またはPCで `npx serve .` 等、簡易HTTPサーバーで配信）
3. PCとスマホを同じWi-Fiに接続し、表示されたURL（例: `http://192.168.x.x:5500`）にスマホの
   ブラウザからアクセスする

※ `index.html` をダブルクリックしてブラウザで直接開く（`file://...`）だけでも動作します。
　 Vue本体は `unpkg.com` から読み込むため、スマホ・PCともにインターネット接続が必要です。

## 収録している画面
- ホーム地図（検索バー・カテゴリ・行きたい度の凡例・日付ナビ）
- 検索サジェスト → 検索結果（全て／過去にピン／未ピン の3タブ）
- スポット詳細 → 行きたい度を選んでピン登録（＝ルート追加）
- ルートリスト（ポップアップ）
- 出発前設定（終了時間スライダーで組み込み件数がリアルタイムに変化）
- 結果画面（タイムライン・除外ピンの明示）
- ルート編集（並べ替え・削除・追加・滞在時間調整）
- 案内中（現在地・次の目的地・場所紹介）
- 動的リルート確認（複数の代替案から選択）
- **リルートの設定**（あなたのスタイル／並び替えの優先順位／フルカスタマイズで
  重視するポイント・食事と休憩・移動の条件・固定したい場所・リルートの動き）
  → 動的リルート確認シートの「⚙ 並び替えの基準を変える」から遷移します
- 旅のあと・ふりかえり

## 注意点（デモの制約）
- バックエンドはありません。全データはブラウザのメモリ上だけで動きます（リロードで初期化）。
- 位置情報・実際の地図APIは使用していません。「地図」はイメージ用のダミー表示です。
- 「レビュー」「メモ」など一部ボタンはトースト表示のみで、実装はされていません。
